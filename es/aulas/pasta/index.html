Clase 3 · 16 min

La carpeta es el contexto: README, AGENTS.md y Markdown

Cuando todo queda en una sola carpeta, la IA lee material que no tiene nada que ver con el pedido y no sabes de dónde salió cada frase. Una carpeta por tema, con un archivo para personas y otro para el agente, resuelve eso antes del primer pedido.

Empezar la clase

En esta clase vas a

  1. 1Una carpeta por tema, y config para lo que vale en todos
  2. 2Las tres marcas del Markdown: #, ## y -
  3. 3README para personas, AGENTS.md para el agente
  4. 4Editar con notepad y comprobar con type

Objetivo: armar el árbol projetos/config y la carpeta del proyecto con entradas, saidas, README.md y AGENTS.md en Markdown.

Cada cajón guarda un tema. Haz clic en cada parte.

  1. 1/5

    projetos

    Reúne trabajos independientes. Cada carpeta dentro de ella es un contexto: el material de un solo tema. Cuando abres el agente en una carpeta, él trabaja a partir de ella.

  2. 2/5

    config

    Queda dentro de projetos, pero fuera de cada proyecto. Guarda lo que vale siempre, como "prefiero informes cortos, con los pendientes al final". Lo escribes una vez y lo usas en todos.

  3. 3/5

    meu-primeiro-agente

    Entradas es lo que la IA lee; saídas es lo que ella produce, para que tú lo revises. Separadas, se puede comparar una con la otra. No mezcles aquí material de otro cliente o de otro grupo.

  4. 4/5

    Agente

    El agente busca el AGENTS.md por sí solo al empezar. Lo demás lo lee cuando tú se lo indicas: la IA no abre cada archivo de la carpeta por cuenta propia.

  5. 5/5

    Menos material, más rastro

    Una carpeta separada por tema hace que la IA lea menos cosas y te deja saber de dónde vino cada frase. Dibuja el árbol en papel antes de crear: los nombres salen con calma.

Nombres cortos, sin espacios y sin tildes: meu-primeiro-agente, entradas, saidas.

02 · Markdown y los dos archivos

Texto organizado con tres marcas.

1. Tres marcas

El # al comienzo de la línea hace un título, ## hace un subtítulo y el guion hace un ítem de lista. El archivo termina en .md y se abre en cualquier editor de texto.

Sigue siendo texto: quien lo lee entiende la estructura incluso sin formato.

En el archivo# Feira de ciências ## Materiais - algodão e um copo

2. README

Dice para qué sirve el proyecto y cómo comprobar el resultado. Cinco secciones: Propósito, Leia primeiro, Organização, Como verificar y Estado atual.

¿Aún no sabes un campo? Escribe "a definir". Un campo honesto abierto vale más que un texto de plantilla que nadie revisó.

Cómo verificarTodo grupo inscrito aparece en la lista final.

3. AGENTS.md

Le dice al agente quién eres, las reglas del proyecto y qué hay en la carpeta. Claude Code y Codex leen el mismo archivo, así que las reglas valen para los dos.

Empieza con tres reglas tuyas. En la clase 7 crece y gana reglas que puedes comprobar.

ReglaAntes de terminar, dime qué cambió y cómo lo reviso.

4. Editar y comprobar

notepad README.md abre el archivo en el Bloc de notas; Ctrl+S lo guarda. type README.md muestra en el cmd lo que quedó guardado.

Los acentos cambiados en el cmd, como Ã§ en lugar de ç, son solo la pantalla; el archivo está bien.

En Mac y en Linuxnano README.md para editar, cat README.md para ver.

03 · El árbol y los dos archivos

Crea las carpetas desde el cmd y pega las plantillas en el Bloc de notas. Cambia lo que esté entre < >.

cmd · las carpetas
cd %USERPROFILE%\projetos
mkdir config
cd meu-primeiro-agente
mkdir entradas
mkdir saidas
dir /b
README.md
# Meu primeiro agente

## Propósito
<qué produce este proyecto, en una frase>

## Lee primero
1. AGENTS.md
2. ../config/decisoes.md
3. ../config/memoria.md

## Organización
- entradas: lo que la IA lee
- saidas: lo que ella produce, para que yo revise

## Cómo verificar
<cómo alguien comprueba que el resultado está correcto>

## Estado actual
Por definir.
AGENTS.md
# Quién soy
<tu nombre, tu profesión, para quién trabajas>

# Reglas de este proyecto
- Escribe en español, frases cortas.
- Trabaja solo dentro de esta carpeta. No borres archivos sin preguntar.
- Antes de terminar, dime qué cambió y cómo lo reviso.

# Qué hay aquí
- entradas/: material que puedes leer
- saidas/: donde entregas los borradores
cmd · crear, editar y comprobar
notepad README.md
notepad AGENTS.md
type AGENTS.md
Simulación: ejemplo ilustrativo
C:\Users\ana\projetos
├─ config
└─ meu-primeiro-agente
   ├─ AGENTS.md
   ├─ README.md
   ├─ entradas
   └─ saidas

El Bloc de notas pregunta si quieres crear el archivo nuevo: responde Sí. Guarda con Ctrl+S y cierra.

  • El archivo se vuelve AGENTS.md.txt: en el Bloc de notas, en Tipo, elige "Todos los archivos", o créalo con notepad AGENTS.md en el cmd.
  • Todo en la carpeta Documentos: el agente lee exámenes, contratos y notas que no tienen que ver con la tarea.
  • Preferencia repetida en cada proyecto: vive una sola vez, en config.

Crea las carpetas y comprueba, como en tu computadora.
