Clase 2 · 18 min

Instalar desde la fuente oficial e iniciar sesión con tu cuenta

Instalar el programa, iniciar sesión con la cuenta y abrir en la carpeta son tres etapas distintas, cada una con su comprobación. El comando viene de la página oficial, la cuenta es tu suscripción y ninguna contraseña pasa por el terminal.

Empezar la clase

En esta clase vas a

  1. 1Instalar Git, GitHub CLI y Node con winget
  2. 2Instalar Claude Code o Codex desde la dirección oficial
  3. 3Confirmar con --version después de volver a abrir el cmd
  4. 4Iniciar sesión con la suscripción y comprobar el método, sin exponer ninguna clave

Objetivo: instalar Git, gh, Node y el agente (Claude Code o Codex) desde el cmd y confirmar la versión y el método de inicio de sesión.

01 · De cero al agente abierto

Tres etapas, cada una con su "comprobación".

Clase 201 · De cero al agente abiertoTres etapas, cada una con su "comprobación".

1/4

Instalar el programa

Instalar pone el programa en el computador. Eso todavía no conecta tu cuenta ni elige la carpeta. Después de instalar, cierra el cmd y ábrelo de nuevo: solo la ventana nueva ve el programa que llegó.

Desplázate por la página: cada etapa de abajo enciende su parte del diagrama.

  1. 1/4

    Instalar el programa

    Instalar pone el programa en el computador. Eso todavía no conecta tu cuenta ni elige la carpeta. Después de instalar, cierra el cmd y ábrelo de nuevo: solo la ventana nueva ve el programa que llegó.

  2. 2/4

    Iniciar sesión con la cuenta

    Como la credencial en el torniquete: el terminal te manda al navegador y es allí donde inicias sesión. La contraseña nunca pasa por el terminal. Iniciar sesión con la cuenta usa el plan de la suscripción; una clave de API cobra por consumo, en otra cuenta.

  3. 3/4

    Abrir en la carpeta

    El agente trabaja en la carpeta en la que fue abierto. La primera vez en una carpeta te pregunta si confías en ella: es tu carpeta de práctica, confirma. Para salir, /quit en Codex o /exit en Claude Code.

  4. 4/4

    Una etapa a la vez

    Instalaste, comprueba la versión. Iniciaste sesión, comprueba el método. Abriste, comprueba la carpeta. Si algo falla, sabes exactamente en cuál de las tres te quedaste.

Justo después de instalar, abrir el agente y ver la solicitud de inicio de sesión no es un defecto: la etapa 1 salió bien y falta la 2.

02 · Revisa el sello antes de abrir la caja

Cuatro cuidados que valen para cualquier programa nuevo.

1. Fuente oficial

En internet circulan comandos "más rápidos". Un comando pegado sin revisar puede ejecutar cualquier cosa.

Lee el remitente: Git.Git, GitHub.cli, OpenJS.NodeJS.LTS, @openai/codex, claude.ai/install.cmd. Un nombre distinto, de una página desconocida, no se pega.

Señal de alertaUn paquete con "codex" en el nombre, pero sin el @openai/ delante.

2. Esperar el >

Pega un comando, espera a que termine y a que vuelva el >. Las líneas que pasan no tienes que entenderlas.

La primera vez, winget puede preguntarte si aceptas los términos del origen: escribe Y y Enter.

Lo que apareceInstalado con êxito

3. Reabrir y comprobar

Cierra el cmd y ábrelo de nuevo. Entonces git --version, gh --version y claude --version o codex --version responden con un número.

"No se reconoce como un comando interno o externo" casi siempre es solo la ventana vieja.

Regla¿Instalaste? Cierra y abre el cmd antes de comprobar.

4. Método de entrada

La primera vez que se abre, el agente te pide iniciar sesión: usa tu suscripción. En Codex, codex login abre el navegador y codex login status te dice por qué camino entraste.

En la ficha del proyecto va el método ("cuenta" o "API"). La clave en sí nunca va en la ficha, en el pedido ni en una captura.

03 · Los comandos de instalación

Una vez por computadora. Copia un bloque, espera a que termine, cierra y vuelve a abrir el cmd.

cmd · Git, GitHub CLI y Node
winget install --id Git.Git -e
winget install --id GitHub.cli -e
winget install --id OpenJS.NodeJS.LTS -e
cmd · el agente (elige uno, o los dos)
rem Claude Code:
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

rem Codex:
npm install -g @openai/codex
cmd · en una ventana NUEVA, comprueba
git --version
gh --version
claude --version
codex --version
cmd · iniciar sesión y comprobar el método (Codex)
codex login
codex login status
cmd · abrir el agente en la carpeta del proyecto
cd %USERPROFILE%\projetos\meu-primeiro-agente
cd
claude
Simulación: ejemplo ilustrativo
C:\Users\ana> winget install --id OpenJS.NodeJS.LTS -e
Instalado com êxito
C:\Users\ana> rem fechou o cmd e abriu outro
C:\Users\ana> npm install -g @openai/codex
added 1 package in 9s
C:\Users\ana> codex login status
Logged in using ChatGPT

Los números de versión y los tiempos cambian con el tiempo. Lo que importa es que aparezca un número, y no el mensaje de error.

  • "… no se reconoce como un comando interno o externo": cierra el cmd, ábrelo de nuevo y repite.
  • winget pidió aceptar términos: Y y Enter.
  • login status muestra una clave de API y querías la cuenta: codex logout y después codex login.
  • El agente pregunta si confías en la carpeta: es tu carpeta de entrenamiento, confirma.

En la Terminal de Mac o de Linux, Claude Code se instala con curl -fsSL https://claude.ai/install.sh | bash y Codex con npm install -g @openai/codex (primero va Node). La comprobación es la misma: --version en una ventana nueva.

Misiones

  4. 4Ahora comprueba Git de nuevo.
