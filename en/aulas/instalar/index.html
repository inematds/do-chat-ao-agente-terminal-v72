Lesson 2 · 18 min

Install from the official source and sign in with your account

Installing the program, signing in with your account, and opening it in the folder are three different steps, each with its own check. The command comes from the official page, the account is your subscription, and no password passes through the terminal.

Start the lesson

In this lesson you will

  1. 1Install Git, GitHub CLI, and Node with winget
  2. 2Install Claude Code or Codex from the official address
  3. 3Confirm with --version after reopening cmd
  4. 4Sign in with your subscription and check the method, without exposing any key

Goal: install Git, gh, Node, and the agent (Claude Code or Codex) from cmd and confirm the version and sign-in method.

01 · From zero to an open agent

Three steps, each with its own "check."

  1. 1/4

    Install the program

    Installing puts the program on your computer. It does not yet connect your account or choose the folder. After installing, close cmd and open it again: only the new window can see the program that just arrived.

  2. 2/4

    Sign in with your account

    Like a badge at a turnstile: the terminal sends you to the browser, and that is where you sign in. Your password never passes through the terminal. Signing in with your account uses your subscription plan; an API key bills by usage, on a different account.

  3. 3/4

    Open in the folder

    The agent works in the folder where it was opened. The first time in a folder, it asks whether you trust it: this is your practice folder, so confirm. To exit, type /quit in Codex or /exit in Claude Code.

  4. 4/4

    One step at a time

    Installed? Check the version. Signed in? Check the method. Opened? Check the folder. If something fails, you know exactly which of the three steps it stopped at.

Right after installing, opening the agent and seeing a login prompt is not a bug: step 1 worked and step 2 is still missing.

02 · Check the seal before opening the box

Four precautions that apply to any new program.

1. Official source

"Faster" commands are going around the internet. A command pasted without checking can run anything.

Read the sender: Git.Git, GitHub.cli, OpenJS.NodeJS.LTS, @openai/codex, claude.ai/install.cmd. A different name, from an unknown page, is not something you paste.

Warning signA package with "codex" in the name but without @openai/ in front of it.

2. Wait for the >

Paste one command, wait for it to finish and for the > to come back. You don't need to understand the lines that scroll by.

The first time, winget may ask if you accept the source terms: type Y and press Enter.

What shows upSuccessfully installed

3. Reopen and check

Close cmd and open it again. Then git --version, gh --version and claude --version or codex --version answer with a number.

"Is not recognized as an internal or external command" is almost always just the old window.

RuleInstalled it? Close and reopen cmd before checking.

4. Sign-in method

The first time it opens, the agent asks you to sign in: use your subscription. In Codex, codex login opens the browser and codex login status tells you which way you signed in.

The project sheet records the method ("account" or "API"). The key itself never goes into a sheet, a request or a screenshot.

03 · The install commands

Once per computer. Copy one block, wait for it to finish, close and reopen cmd.

cmd · Git, GitHub CLI and Node
winget install --id Git.Git -e
winget install --id GitHub.cli -e
winget install --id OpenJS.NodeJS.LTS -e
cmd · the agent (pick one, or both)
rem Claude Code:
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

rem Codex:
npm install -g @openai/codex
cmd · in a NEW window, check
git --version
gh --version
claude --version
codex --version
cmd · sign in and check the method (Codex)
codex login
codex login status
cmd · open the agent in the project folder
cd %USERPROFILE%\projetos\meu-primeiro-agente
cd
claude

Version numbers and times change over time. What matters is that a number shows up, not the error message.

  • "… is not recognized as an internal or external command": close cmd, open it again and repeat.
  • winget asked you to accept terms: Y and Enter.
  • login status shows an API key and you wanted the account: codex logout and then codex login.
  • The agent asks if you trust the folder: it's your practice folder, confirm.

In the Terminal on Mac or Linux, Claude Code installs with curl -fsSL https://claude.ai/install.sh | bash and Codex with npm install -g @openai/codex (Node comes first). The check is the same: --version in a new window.
