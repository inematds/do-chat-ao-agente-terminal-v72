Lesson 3 · 16 min

The folder is the context: README, AGENTS.md and Markdown

When everything sits in a single folder, the AI reads material that has nothing to do with your request and you don't know where each sentence came from. One folder per subject, with one file for people and another for the agent, fixes this before the first request.

Start the lesson

In this lesson you will

  1. 1One folder per subject, and config for what applies to all of them
  2. 2The three Markdown marks: #, ## and -
  3. 3README for people, AGENTS.md for the agent
  4. 4Edit with Notepad and check with type

Goal: set up the projetos/config tree and the project folder with entradas, saídas, README.md and AGENTS.md in Markdown.

    A separate folder for each subject makes the AI read less and lets you know where each sentence came from. Draw the tree on paper before you create it: the names come out calmly.

Short names, no spaces and no accents: meu-primeiro-agente, entradas, saidas.

02 · Markdown and the two files

Organized text with three marks.

1. Three marks

The # at the start of a line makes a title, ## makes a subtitle, and the hyphen makes a list item. The file ends in .md and opens in any text editor.

It's still just text: whoever reads it understands the structure even without formatting.

In the file# Feira de ciências ## Materiais - algodão e um copo

2. README

It says what the project is for and how to check the result. Five sections: Propósito, Leia primeiro, Organização, Como verificar and Estado atual.

Don't know a field yet? Write "a definir". An honest open field is worth more than template text nobody checked.

How to checkEvery registered group appears in the final list.

3. AGENTS.md

It tells the agent who you are, the project's rules, and what's in the folder. Claude Code and Codex read the same file, so the rules apply to both.

Start with three rules of your own. In lesson 7 it grows and gets rules you can check.

RuleBefore you finish, tell me what changed and how I can check it.

4. Edit and check

notepad README.md opens the file in Notepad; Ctrl+S saves it. type README.md shows in cmd what was saved.

Swapped accents in cmd, like Ã§ in place of ç, are only the screen; the file is fine.

On Mac and Linuxnano README.md to edit, cat README.md to view.

03 · The tree and the two files

Create the folders in cmd and paste the templates into Notepad. Replace whatever is between < >.

cmd · the folders
cd %USERPROFILE%\projetos
mkdir config
cd meu-primeiro-agente
mkdir entradas
mkdir saidas
dir /b
README.md
# Meu primeiro agente

## Purpose
<what this project produces, in one sentence>

## Read first
1. AGENTS.md
2. ../config/decisoes.md
3. ../config/memoria.md

## Organization
- entradas: what the AI reads
- saidas: what it produces, for me to review

## How to check
<how someone confirms the result is right>

## Current status
To be defined.
AGENTS.md
# Who I am
<your name, your profession, who you work for>

# Rules for this project
- Write in English, short sentences.
- Work only inside this folder. Do not delete files without asking.
- Before you finish, tell me what changed and how I can check it.

# What is here
- entradas/: material you can read
- saidas/: where you deliver the drafts
cmd · create, edit and check
notepad README.md
notepad AGENTS.md
type AGENTS.md
Simulation: illustrative example

Notepad asks if you want to create the new file: answer Yes. Save with Ctrl+S and close.

  • The file becomes AGENTS.md.txt: in Notepad, under Save as type, choose "All files", or create it with notepad AGENTS.md in cmd.
  • Everything in the Documents folder: the agent reads tests, contracts and notes that have nothing to do with the task.
  • Same preference repeated in every project: it lives only once, in config.
