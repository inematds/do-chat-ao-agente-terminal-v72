Aula 2 · 18 min

Instalar da fonte oficial e entrar com a sua conta

Colocar o programa, entrar com a conta e abrir na pasta são três etapas diferentes, cada uma com a sua conferência. O comando vem da página oficial, a conta é a sua assinatura e nenhuma senha passa pelo terminal.

Começar a aula

Nesta aula você vai

  1. 1Instalar Git, GitHub CLI e Node com o winget
  2. 2Instalar o Claude Code ou o Codex pelo endereço oficial
  3. 3Confirmar com --version depois de reabrir o cmd
  4. 4Entrar pela assinatura e conferir o método, sem expor chave

Objetivo: instalar Git, gh, Node e o agente (Claude Code ou Codex) pelo cmd e confirmar versão e método de entrada.

01 · Do zero ao agente aberto

Três etapas, cada uma com o seu "confere".

Aula 201 · Do zero ao agente abertoTrês etapas, cada uma com o seu "confere".

1/4

Colocar o programa

Instalar põe o programa no computador. Isso ainda não conecta a sua conta nem escolhe a pasta. Depois de instalar, feche o cmd e abra de novo: só a janela nova enxerga o programa que chegou.

Role a página: cada etapa abaixo acende a sua parte do diagrama.

  1. 1/4

    Colocar o programa

    Instalar põe o programa no computador. Isso ainda não conecta a sua conta nem escolhe a pasta. Depois de instalar, feche o cmd e abra de novo: só a janela nova enxerga o programa que chegou.

  2. 2/4

    Entrar com a conta

    Como o crachá na catraca: o terminal manda você ao navegador e é lá que você entra. A senha nunca passa pelo terminal. Entrar com a conta usa o plano da assinatura; uma chave de API cobra por consumo, em outra conta.

  3. 3/4

    Abrir na pasta

    O agente trabalha na pasta em que foi aberto. Na primeira vez numa pasta ele pergunta se você confia nela: é a sua pasta de treino, confirme. Para sair, /quit no Codex ou /exit no Claude Code.

  4. 4/4

    Uma etapa de cada vez

    Instalou, confere a versão. Entrou, confere o método. Abriu, confere a pasta. Se algo falhar, você sabe exatamente em qual das três parou.

Logo depois de instalar, abrir o agente e ver o pedido de login não é defeito: a etapa 1 deu certo e falta a 2.

02 · Confira o lacre antes de abrir a caixa

Quatro cuidados que valem para qualquer programa novo.

1. Fonte oficial

Na internet circulam comandos "mais rápidos". Um comando colado sem conferir pode executar qualquer coisa.

Leia o remetente: Git.Git, GitHub.cli, OpenJS.NodeJS.LTS, @openai/codex, claude.ai/install.cmd. Nome diferente, de página desconhecida, não se cola.

Sinal de alertaUm pacote com "codex" no nome, mas sem o @openai/ na frente.

2. Esperar o >

Cole um comando, espere terminar e o > voltar. As linhas que passam você não precisa entender.

Na primeira vez, o winget pode perguntar se você aceita os termos da origem: digite Y e Enter.

O que apareceInstalado com êxito

3. Reabrir e conferir

Feche o cmd e abra de novo. Então git --version, gh --version e claude --version ou codex --version respondem um número.

"Não é reconhecido como um comando interno ou externo" quase sempre é só a janela velha.

RegraInstalou? Feche e abra o cmd antes de conferir.

4. Método de entrada

Na primeira vez que abre, o agente pede para entrar: use a sua assinatura. No Codex, codex login abre o navegador e codex login status diz por qual caminho você entrou.

Na ficha do projeto vai o método ("conta" ou "API"). A chave em si nunca vai para ficha, pedido ou print.

03 · Os comandos de instalação

Uma vez por computador. Copie um bloco, espere terminar, feche e reabra o cmd.

cmd · Git, GitHub CLI e Node
winget install --id Git.Git -e
winget install --id GitHub.cli -e
winget install --id OpenJS.NodeJS.LTS -e
cmd · o agente (escolha um, ou os dois)
rem Claude Code:
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

rem Codex:
npm install -g @openai/codex
cmd · numa janela NOVA, confira
git --version
gh --version
claude --version
codex --version
cmd · entrar e conferir o método (Codex)
codex login
codex login status
cmd · abrir o agente na pasta do projeto
cd %USERPROFILE%\projetos\meu-primeiro-agente
cd
claude

Os números de versão e os tempos mudam com o tempo. O que importa é aparecer um número, e não a mensagem de erro.

  • "… não é reconhecido como um comando interno ou externo": feche o cmd, abra de novo e repita.
  • O winget pediu para aceitar termos: Y e Enter.
  • login status mostra uma chave de API e você queria a conta: codex logout e depois codex login.
  • O agente pergunta se confia na pasta: é a sua pasta de treino, confirme.

No Terminal do Mac ou do Linux, o Claude Code se instala com curl -fsSL https://claude.ai/install.sh | bash e o Codex com npm install -g @openai/codex (o Node vem antes). A conferência é a mesma: --version numa janela nova.

04 · Ensaie: instalar e conferir

Repare no que acontece quando você confere na mesma janela.

Missões

  1. 1Instale o Git pelo winget (nome exato: Git.Git).
  2. 2Confira se o Git responde, nesta mesma janela.
  3. 3Feche esta janela (o comando é exit).
  4. 4Agora confira o Git de novo.
  5. 5Confira por qual método o Codex entrou.
