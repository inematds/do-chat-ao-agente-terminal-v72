Aula 3 · 16 min

A pasta é o contexto: README, AGENTS.md e Markdown

Quando tudo fica numa pasta só, a IA lê material que não tem nada a ver com o pedido e você não sabe de onde veio cada frase. Uma pasta por assunto, com um arquivo para pessoas e outro para o agente, resolve isso antes do primeiro pedido.

Começar a aula

Nesta aula você vai

  1. 1Uma pasta por assunto, e config para o que vale em todos
  2. 2As três marcas do Markdown: #, ## e -
  3. 3README para pessoas, AGENTS.md para o agente
  4. 4Editar com notepad e conferir com type

Objetivo: montar a árvore projetos/config e a pasta do projeto com entradas, saídas, README.md e AGENTS.md em Markdown.

01 · A árvore de trabalho

Cada gaveta guarda um assunto. Clique em cada parte.

1/5

projetos

Role a página: cada etapa abaixo acende a sua parte do diagrama.

  1. 1/5

    projetos

    Reúne trabalhos independentes. Cada pasta dentro dela é um contexto: o material de um assunto só. Quando você abre o agente numa pasta, ele trabalha a partir dela.

  2. 2/5

    config

    Fica dentro de projetos, mas fora de cada projeto. Guarda o que vale sempre, como "prefiro relatórios curtos, com as pendências no fim". Escreve uma vez, usa em todos.

  3. 3/5

    meu-primeiro-agente

    Entradas é o que a IA lê; saídas é o que ela produz, para você revisar. Separadas, dá para conferir uma contra a outra. Não misture aqui material de outro cliente ou de outra turma.

  4. 4/5

    Agente

    O agente procura o AGENTS.md sozinho ao começar. O resto ele lê quando você aponta: a IA não abre cada arquivo da pasta por conta própria.

  5. 5/5

    Menos material, mais rastro

    Pasta separada por assunto faz a IA ler menos coisa e deixa você saber de onde veio cada frase. Desenhe a árvore no papel antes de criar: os nomes saem com calma.

Nomes curtos, sem espaço e sem acento: meu-primeiro-agente, entradas, saidas.

02 · Markdown e os dois arquivos

Texto organizado com três marcas.

1. Três marcas

O # no começo da linha faz título, ## faz subtítulo e o hífen faz item de lista. O arquivo termina em .md e abre em qualquer editor de texto.

Continua sendo texto: quem lê entende a estrutura mesmo sem formatação.

No arquivo# Feira de ciências ## Materiais - algodão e um copo

2. README

Diz para que serve o projeto e como conferir o resultado. Cinco seções: Propósito, Leia primeiro, Organização, Como verificar e Estado atual.

Ainda não sabe um campo? Escreva "a definir". Campo honesto em aberto vale mais que texto de modelo que ninguém conferiu.

Como verificarTodo grupo inscrito aparece na lista final.

3. AGENTS.md

Diz ao agente quem é você, as regras do projeto e o que tem na pasta. Claude Code e Codex leem o mesmo arquivo, então as regras valem para os dois.

Comece com três regras suas. Na aula 7 ele cresce e ganha regras que dá para conferir.

RegraAntes de terminar, diga o que mudou e como eu confiro.

4. Editar e conferir

notepad README.md abre o arquivo no Bloco de Notas; Ctrl+S grava. type README.md mostra no cmd o que ficou gravado.

Acentos trocados no cmd, como Ã§ no lugar de ç, são só a tela; o arquivo está certo.

No Mac e no Linuxnano README.md para editar, cat README.md para ver.

03 · A árvore e os dois arquivos

Crie as pastas pelo cmd e cole os modelos no Bloco de Notas. Troque o que estiver entre < >.

cmd · as pastas
cd %USERPROFILE%\projetos
mkdir config
cd meu-primeiro-agente
mkdir entradas
mkdir saidas
dir /b
README.md
# Meu primeiro agente

## Propósito
<o que este projeto produz, em uma frase>

## Leia primeiro
1. AGENTS.md
2. ../config/decisoes.md
3. ../config/memoria.md

## Organização
- entradas: o que a IA lê
- saidas: o que ela produz, para eu revisar

## Como verificar
<como alguém confere se o resultado está certo>

## Estado atual
A definir.
AGENTS.md
# Quem sou
<seu nome, sua profissão, para quem você trabalha>

# Regras deste projeto
- Escreva em português, frases curtas.
- Trabalhe só dentro desta pasta. Não apague arquivos sem perguntar.
- Antes de terminar, diga o que mudou e como eu confiro.

# O que tem aqui
- entradas/: material que você pode ler
- saidas/: onde você entrega os rascunhos
cmd · criar, editar e conferir
notepad README.md
notepad AGENTS.md
type AGENTS.md

C:\Users\ana\projetos

O Bloco de Notas pergunta se quer criar o arquivo novo: responda Sim. Grave com Ctrl+S e feche.

  • Arquivo vira AGENTS.md.txt: no Bloco de Notas, em Tipo, escolha "Todos os arquivos", ou crie pelo notepad AGENTS.md no cmd.
  • Tudo na pasta Documentos: o agente lê provas, contratos e notas que não têm a ver com a tarefa.
  • Preferência repetida em cada projeto: ela mora uma vez só, em config.

04 · Ensaie: montar a árvore

Crie as pastas e confira, como no seu computador.

Missões

  1. 1Crie a pasta config aqui em projetos.
  2. 2Entre em meu-primeiro-agente.
  3. 3Crie a pasta entradas.
  4. 4Crie a pasta saidas (sem acento).
  5. 5Abra o AGENTS.md no Bloco de Notas.
  6. 6Liste só os nomes do que tem na pasta.
  7. 7Mostre o AGENTS.md no terminal.
